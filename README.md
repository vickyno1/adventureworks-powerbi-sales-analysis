# AdventureWorks Sales Analysis – Power BI

## Project Overview
An interactive Power BI dashboard project built using the AdventureWorks dataset to analyze sales performance, revenue, costs, profitability, and product performance.

The project focuses on converting raw business data into meaningful insights through interactive dashboards and visualizations.

## Tools Used
- Power BI Desktop
- Power Query
- DAX
- Data Visualization
- Data Analysis

## Dashboard Pages

### 1. Sales Performance Details
- Product-level sales performance
- Total customers and orders
- Revenue, cost, and profit analysis
- Year-to-date revenue
- Previous month revenue
- Month-over-month changes

### 2. Sales Overview Dashboard
- Total products, cost, orders, customers, revenue, and profit KPIs
- Monthly revenue trend
- Top 10 products by revenue
- Revenue distribution by country
- Revenue distribution by gender
- Country-based filtering

### 3. Product Performance Analysis
- Revenue by product model
- Revenue and profit by subcategory
- Profit by product model
- Product sales and profit summary matrix
- Product hierarchy analysis

### 4. Executive Insights Dashboard
- Revenue contribution by product subcategory
- Profit achievement
- Revenue achievement

## Key Business Metrics
- Total Products
- Total Orders
- Total Customers
- Total Cost
- Total Revenue
- Total Profit
- Profit Percentage
- Revenue YTD
- Month-over-Month Change

## Project Files
- `AdventureWorks_Sales_Dashboard.pbix` – Interactive Power BI report.
- `AdventureWorks_Sales_Dashboard.pdf` – PDF dashboard preview.

## Skills Demonstrated
- Data analysis and business reporting
- DAX calculations and measures
- Interactive dashboard development
- KPI design
- Product and sales performance analysis
- Data visualization

## Project Objective
To demonstrate how Power BI can be used to analyze business performance, identify sales trends, evaluate product profitability, and communicate insights through interactive dashboards.
